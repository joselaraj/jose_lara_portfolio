NFL Stat Dashboard

A full-stack stats dashboard for NFL players. A Django REST Framework API backed by MySQL serves position-by-position data (QB, RB, WR, kicker) pulled in with nflreadpy and Polars; a React frontend renders it with Recharts across stat cards, tables, and charts. Deployed with the backend on Railway and the frontend on Vercel.

Car Price Tracker

A price-drop tracker for used car listings, built on the Auto.dev API instead of scraping sites like Cars.com or CarGurus, whose terms of service prohibit it. Django models track searches, listings, and price history; Celery and Redis run the polling in the background and send an email the moment a tracked listing's price drops.
